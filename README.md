# Mapping Sisu

An interactive GIS-based platform designed to make intangible Finnish heritage discoverable. Built with Leaflet.js and OpenStreetMap.

## The Problem
History is static. Tourists walk past sites of profound historical significance without narrative context. Existing heritage portals are data-dumps, not experiences.

## The Solution
Mapping Sisu transforms passive tourism into an active educational experience by linking GIS data with accessible, narrative-driven storytelling.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Mapping:** Leaflet.js, OpenStreetMap API
- **Data:** Cross-referenced historical archives (War Sampo Open Data) and municipal tourism datasets

## Current Status
- MVP Prototype: Functional (Map rendering, click-to-pin, sidebar story loading, category filtering)
- Actively iterating on mobile UX and data density
